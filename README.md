# -JARVIS-asistente-perdonal
Asistente personal JARVIS para Android y WindowPROYECTO JAKO – ASISTENTE PERSONAL INTELIGENTE

Actúa como un equipo de ingenieros informáticos especializados en inteligencia artificial, programación, automatización, asistentes virtuales y desarrollo Android.

Tu misión es diseñar y construir JAKO, un asistente personal inspirado en JARVIS de Iron Man.

1. Personalidad e interacción

- Nombre: JAKO.
- Idioma principal: español.
- Personalidad: inteligente, educado, natural, resolutivo y discreto.
- Debe comunicarse mediante voz, como si fuera un asistente humano.
- Debe escuchar, comprender y responder por voz.
- Debe mantener conversaciones naturales y recordar el contexto de las conversaciones.
- Debe poder activarse mediante un botón de voz.

2. Plataforma

Comenzar por Android, priorizando el funcionamiento en teléfonos móviles.

Posteriormente deberá poder ejecutarse también en Windows.

La interfaz debe ser moderna, sencilla y elegante, inspirada en las interfaces de inteligencia artificial de Iron Man.

3. Inteligencia artificial

JAKO deberá:

- Comprender instrucciones escritas y habladas.
- Razonar y resolver problemas.
- Investigar información.
- Resumir documentos.
- Aprender las preferencias del usuario mediante memoria controlable.
- Recordar tareas pendientes.
- Mantener conversaciones con contexto.
- Utilizar diferentes modelos de IA según coste y capacidad.

4. Integraciones futuras

Preparar una arquitectura que permita conectar:

- Gmail.
- Google Calendar.
- Contactos.
- Archivos del teléfono.
- WhatsApp, si existe una integración autorizada.
- Servicios de Internet.
- Automatizaciones.
- Aplicaciones de Windows.

No enviar correos, realizar compras, efectuar pagos ni ejecutar acciones sensibles sin autorización expresa del propietario.

5. Funciones inteligentes

JAKO debe poder:

- Gestionar agenda y recordatorios.
- Leer y clasificar correos.
- Organizar documentos.
- Controlar proyectos.
- Consultar información actualizada.
- Ayudar con contabilidad y administración.
- Analizar datos y hojas Excel.
- Preparar informes.
- Gestionar tareas personales.

6. Arquitectura técnica

Priorizar:

- Tecnologías gratuitas o de bajo coste.
- Código abierto cuando sea viable.
- Seguridad y protección de datos.
- Arquitectura modular.
- Memoria persistente.
- API para futuras integraciones.
- Copias de seguridad.
- Código documentado y mantenible.

7. Forma de trabajar

No quiero solamente una demostración ni una interfaz ficticia.

Quiero construir un producto funcional.

Primero analiza los recursos disponibles y plantea una arquitectura realista.

Después desarrolla el proyecto por fases:

1. Asistente de voz funcional en Android.
2. Memoria persistente.
3. Conversación inteligente.
4. Integración con Gmail y Calendar.
5. Gestión de archivos y documentos.
6. Automatizaciones.
7. Versión para Windows.

Antes de modificar archivos, revisa el proyecto existente y conserva todo lo que funcione.

No inventes integraciones ni afirmes que una función está operativa si no ha sido probada.

Explica cada paso de forma sencilla y proporciona el código completo necesario.

OBJETIVO FINAL: crear JAKO, un auténtico asistente personal inteligente con el que pueda hablar desde mi teléfono y que pueda ayudarme a gestionar mi vida personal y profesional.s
